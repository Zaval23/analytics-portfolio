# Аукционная система (Учебный проект)

**Роль:** Системный аналитик.

В рамках проекта спроектирована информационная система для проведения аукционов. 
Разработан полный комплект проектной документации с использованием нотации UML.

## Разработанные артефакты (UML)
- **Use Case диаграмма** — роли: Менеджер, Бухгалтер; сценарии закупок.
- **Диаграмма классов** — модель данных: пользователи, лоты, ставки, транзакции, отчёты.
- **Диаграмма деятельности** — процесс оформления и обработки заявки.
- **Диаграмма состояний** — жизненный цикл бронирования номера.
- **Диаграмма компонентов** — архитектура: UI, Request Service, Order Service, Database.
- **Диаграмма пакетов** — логическая структура системы (UI, Request Management, Cost Accounting, Order Management, Data Access).
- **Диаграмма развертывания** — физическое размещение компонентов на серверах.
